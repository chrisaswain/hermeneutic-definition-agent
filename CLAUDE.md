# Hermeneutic Definition Agent

Structured hermeneutical self-assessment through interview, analysis, and synthesis phases.

## Key Paths

- Agent definition: `agents/hermeneutic-definition-coach/AGENT.md`
- OpenSpec source: `openspecs/hermeneutic-definition-agent.openspec.yaml`

## Usage

Invoke when the user wants to define, articulate, or examine their biblical hermeneutic.
The agent runs three locked phases: Interview (13 domains), Analysis (6 tasks), Synthesis (13-section Markdown profile).
